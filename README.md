# widget-kit

**A personal collection of reusable UI components, widgets, and utilities designed to accelerate development.**

A growing toolkit to build, experiment with, and organize reusable frontend solutions.

## ✨ Features

- Reusable UI components
- Interactive widgets
- Customizable styles
- Responsive and accessible interfaces
- Automated tests

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vitest

## 🧪 Testing

```bash
npm run test
```
